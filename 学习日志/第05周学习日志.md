# 第05周学习日志

2026年10月4日—10月10日

这一周的内容比前两周更贴近具体代码。变量、表达式、输入输出以及选择和循环，已经可以组合成一些有实际用途的小程序了。我在看课件时，常常把问题换成成绩计算、菜单选择和数字求和来想。这样每个语句都有要解决的事情，比单独背语法更容易记住。

数据类型是我需要格外注意的地方。整数和小数的运算结果可能不同，例如 `5 / 2` 的两个数都是整数，得到的是 2。如果希望得到 2.5，就要让运算按小数的方式进行，例如写成 `5.0 / 2`。计算平均成绩时也是一样，即使最后准备把结果放进 double 变量里，也要先看除法两边的类型，不能以为最后换个变量就能补回已经丢掉的小数。

输入输出看起来简单，实际使用时也有不少细节。`cin` 可以把输入内容读进变量，`cout` 可以把结果显示出来。读取一整行带空格的文字时，就需要考虑 `getline`。如果输入本来应该是数字，却读到了不合适的内容，也要检查输入是否成功。我觉得一个好用的小程序，除了能计算，还应该让使用者看得懂提示和结果。

课件中的输出格式让我想到成绩单。若要统一保留两位小数，可以结合 `fixed` 和 `setprecision(2)`。结果排得整齐，才容易比较不同数据。不过显示时保留几位小数，和数值在内存里究竟保存得多精确，是两件不同的事，这一点要分开理解。

选择结构负责让程序根据条件走不同的路。例如判断是否及格，可以使用 `if`，条件里比较相等要写 `==`，不能和赋值的 `=` 混在一起。多种菜单选项可以用 `switch` 来处理，如果各个分支不需要继续往下执行，就要注意相应的 `break`。这些地方少写一个符号，程序的意思就可能变掉。

循环让我能够描述重复的工作。求 1 到 100 的和，要先准备保存总和的变量，再让每个数依次加入。循环从哪里开始、什么时候结束、每轮怎样变化，都要对应好。`while` 先判断条件，`do-while` 至少执行一次，而计数明确的情况用 `for` 比较直观。这周我越来越觉得，看懂程序需要跟着变量的变化走。以后遇到不确定的循环，我会先用几个较小的数推一遍，检查有没有多算或少算。
