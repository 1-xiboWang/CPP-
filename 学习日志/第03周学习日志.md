# 第03周学习日志

2026年9月20日—9月26日

刚开始接触这门课时，我最关心的是怎样把一段 C++ 代码写出来。这周看完课程介绍、预备知识和绪论，我发现，在记语法之前，先弄清楚程序怎样工作也很有必要。一个程序需要接收什么信息，按照什么规则处理，最后给出什么结果，这几件事想清楚了，写代码才有方向。比如一个求平均成绩的小程序，输入的是成绩，处理中要做求和与除法，输出的才是平均分。

课件介绍了计算机的硬件和软件。我以前容易把内存和硬盘混在一起，现在会把它们的用途分开看：硬盘可以保存源码和文件，内存则参与程序运行时的数据存放。CPU 根据指令进行计算，程序里的数字也需要用计算机能够处理的形式保存。这样再看变量，我觉得它已经不只是纸面上的一个字母了。

这一周让我印象比较深的是二进制。十进制里的数换成二进制，外表变了，表示的数值没有变。例如二进制的 1010 表示十进制的 10。位和字节也不能混用，一个字节有八位。刚看到这些换算时，我觉得离编程有些远，但想到 C++ 中不同数据类型需要占用存储空间，就能理解为什么课前要补这些知识。

小数的表示也让我多留了一点心。我们平时觉得很简单的 0.1，在计算机里未必能够精确保存。因此，程序算出的结果和数学上写出的数之间，有时会有很小的误差。我现在还不准备把所有表示细节都背下来，但至少知道，遇到小数结果不完全相等时，要考虑数据保存方式，不能马上认定加减乘除写错了。

绪论把程序语言和程序开发连在了一起。C++ 源文件是我能阅读和修改的文字，经过编译、链接之后，才会形成可以运行的程序。编译器可以发现一部分语法错误，却不能保证程序的思路一定正确。即使一个程序能启动、能输出，也还要看它是不是回答了原来的问题。

这周的内容更多是在帮我建立一个起点。我希望自己以后看到代码时，能顺着输入、处理和输出把过程说清楚。接下来学习具体语句，我会把它们放回完整的小程序里理解，先把一个简单功能写明白，再逐渐增加内容。
