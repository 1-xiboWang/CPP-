# 第12周学习日志

2026年11月22日—11月26日

截至这周目前的学习，我把注意力放到了数组、指针和动态内存上。这些内容和前面学过的循环、函数、类都有联系。比如要处理一组成绩，数组负责把数据放在一起，循环负责依次处理，函数负责完成统计。程序中各部分的分工，比刚开始只写几条输入输出语句时丰富了很多。

数组让我能够用同一个名字管理一组同类型的数据。声明 `int a[5]` 后，五个元素的下标是 0 到 4，不能把 a[5] 当成第五个元素。二维数组则可以用行和列来理解，很适合表示几名学生的多门成绩。看统计例子时，我会先区分每一层循环对应哪一维，再看总分、平均分和最大值分别在哪个位置更新。

指针刚出现时，我觉得 `&` 和 `*` 很容易看乱。把指针理解为保存地址的变量以后，就能分开看：`&x` 取得 x 的地址，指针保存这个地址，通过 `*p` 可以访问它指向的对象。指针指向数组元素时，加一表示移动到下一个元素，而不是无论什么类型都只增加一个字节。能够这样解释之后，数组下标和指针访问的联系也更容易理解。

数组作为函数参数时，还需要留意长度。常见写法下，函数接收到的是指向元素的指针，不能把形参当成原来的完整数组来计算元素个数。因此可以把长度一并传入。课件还让我注意到，数组本身与指针仍然有区别，不能因为它们在一些表达式中用法接近，就把它们完全看成一样。字符数组保存 C 风格字符串时，还需要留出结尾的 `\0`。

动态内存处理的是运行时才知道数量的情况。读入 n 后，可以用 `new int[n]` 申请相应数组，使用完再用 `delete[]` 释放。单个对象的申请和释放，与数组的申请和释放要正确配对。删除以后继续使用原地址，或者多个指针指向同一份数据却重复释放，都需要避免。我觉得这部分要一直想着数据现在由谁使用、什么时候应该结束使用。

最后看到 vector，我觉得它让管理一组数据方便了不少。`vector<int>` 可以保存整数，`size()` 能取得当前元素数量，还可以根据需要添加元素。遍历时，范围 for 可以让读取每个元素的意思更直接。如果要通过循环修改原来的元素，就要注意使用引用形式。这个星期的内容还值得继续消化，尤其是指针指向哪里、数组长度从哪里得到。我想先把这两点讲清楚，再去阅读更长的程序。
