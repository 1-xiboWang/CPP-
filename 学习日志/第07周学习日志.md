# 第07周学习日志

2026年10月18日—10月24日

这周继续学习函数，我对“调用一次函数”这件事有了更具体的认识。同样是一段交换两个数的代码，参数的写法不同，外面的变量就可能得到不同结果。我发现，读函数时除了看里面做了什么，还要看数据是怎样传进去的，结果又怎样传回来。

值传递可以理解为给函数一份数值副本，函数修改副本时，原来的变量通常保持不变。引用参数则让形参成为原变量的另一个名字，通过它修改数据会影响原变量。指针参数传入的是地址，函数可以按照地址找到相应数据。比如交换两个整数，理解了这几种方式，就能说明为什么有的函数调用完以后，两个原变量没有交换。

递归是另一个需要慢慢顺着过程看的内容。计算阶乘时，可以把较大的问题写成较小问题的结果再乘一个数，但最后必须有停止的条件。我在理解时，会先沿着 `fac(4)`、`fac(3)` 这样的调用往下看，再想返回值如何一层层往回交。每次调用都有自己这一次需要保存的信息，不能把不同调用中的局部变量都当成同一个。

默认参数和函数重载，让函数的使用方式更灵活。默认参数通常从参数列表右边连续设置，调用时可以省去相应的实参。重载则允许同一个函数名对应不同的参数列表。例如处理整数和小数的函数可以使用同一个合适的名字，但不能只改返回类型就算成重载。如果默认参数与多个重载放在一起，也要留意某次调用会不会让编译器无法确定该选哪一个。

课件还讲了 constexpr。我目前的理解是，符合要求的函数在需要常量结果、实参也满足条件时，可以在编译期间完成计算。它并不意味着每一次调用都会提前算完，使用运行时输入作为参数时，仍然可能在程序运行中计算。和 const 放在一起比较，我更容易分清“这个值能不能修改”以及“这个结果什么时候能够算出来”。

这一周最后开始接触类的内容。之前主要用函数组织操作，现在开始考虑把相关数据和操作一起放进 Clock 这样的类中。时、分、秒和设置时间、显示时间放在一起，比散落在主函数里更有条理。我还需要继续熟悉具体写法，不过已经能感觉到，函数这一章学到的参数、返回值和声明，接下来仍然会经常用到。
